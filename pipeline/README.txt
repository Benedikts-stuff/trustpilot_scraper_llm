# README.txt

Hallo! Willkommen beim Review Analyse Tool.

Um das Tool zu starten, musst du nur eine einzige Datei doppelklicken.

ANLEITUNG:
1.  Stelle sicher, dass dieser ganze Ordner entpackt ist (nicht mehr in der ZIP-Datei).
2.  Doppelklicke die Datei: 'start_tool.bat'

WAS PASSIERT DANN?
- Ein schwarzes Konsolen-Fenster oeffnet sich.
- Beim ALLERERSTEN Start werden alle noetigen Pakete installiert. Das kann 5-10 Minuten dauern. Bitte hab Geduld.
- Bei jedem weiteren Start geht es viel schneller.
- Sobald alles fertig geladen ist, oeffnet sich das Tool automatisch in deinem Standard-Webbrowser.

HINWEIS:
- Das schwarze Konsolen-Fenster muss die ganze Zeit geoeffnet bleiben, waehrend du das Tool nutzt!
- Um das Tool zu beenden, schliesse einfach den Browser-Tab UND das schwarze Fenster.
